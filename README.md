# PaleoGenome — Reviving the Lost Code of Life

A world-class, immersive wildlife documentary homepage for **PaleoGenome**, a final-year Deep Learning research project about ancient DNA reconstruction and extinct animal genetics.

## Tech Stack
- **Next.js 14** (App Router, Static Generation)
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- **Lucide Icons**
- **Web Audio API** (Browser-native nature soundscape synthesis)

## Running Locally

```bash
# Development mode
npm run dev

# Or production build & start
npm run build
npm start
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
